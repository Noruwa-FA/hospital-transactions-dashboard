# Hospital Transactions Revenue & Performance Dashboard

**Tools:** SQL (PostgreSQL) + Power BI
**Completed:** December 2025

## Project Overview
Analysed hospital transaction data across specialties, doctors, and procedures using SQL before transforming and visualising findings in Power BI. The goal was to surface revenue performance insights and support resource allocation decisions.

## What I Did
- Wrote SQL queries in PostgreSQL to extract and aggregate transaction records by doctor, specialty, procedure, and location — joining across multiple relational tables to build a clean analytical dataset
- Used SQL GROUP BY and aggregate functions to calculate total revenue, net income, and cost-to-revenue ratios per specialty, then exported structured outputs into Power BI
- Built DAX measures and an interactive Power BI dashboard with slicers for specialty, location, and date range
- Identified top-performing specialties and high-cost procedures to support resource allocation decisions

## Key Skills Demonstrated
- PostgreSQL: multi-table JOINs, GROUP BY, aggregate functions, data extraction
- Power BI: DAX measures, Power Query, interactive dashboards, slicers
- Healthcare data analysis and revenue performance reporting
